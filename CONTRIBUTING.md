# Contributing

Thanks for helping out.

## Report a bug or ask for a feature

Open an [issue](../../issues/new/choose). For bugs, include your macOS version and the steps to reproduce.

## Send a pull request

1. Fork the repo and create a branch.
2. Make your change. Keep it small and focused, and match the style of the surrounding code.
3. Run `swift build` and try the change in the running app.
4. Open a pull request describing what changed and why.

## Build

```sh
swift build
swift run
```

Requires macOS 13+ and Swift 5.9+.

## Conduct

Be kind and assume good faith. Harassment is not tolerated.
